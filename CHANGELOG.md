# Changelog

## v0.1.0

- Initial project scaffold.
- CLI certificate verification for domains, IPs and URLs.
- Plain HTTP reachability checks.
- TLS 1.0, 1.1, 1.2 and 1.3 support probing.
- Root, intermediate and chain verification.
- Hostname and IP SAN verification.
- JSON and text output.
- Browser-based GUI and local API.
- GitHub, GitLab and Gitea CI scaffolding.
